# HDRezka Downloader

Расширение для Chromium-браузеров (Arc, Chrome, Edge). Ловит запрос
`...mp4:hls:manifest.m3u8`, убирает `:hls:manifest.m3u8` и даёт скачать прямой mp4.

## Установка (Arc/Chrome)
1. Откройте `chrome://extensions`, включите «Режим разработчика».
2. «Загрузить распакованное расширение» → папка `extension/`.
3. Запустите видео, нажмите на иконку расширения → «Скачать».
