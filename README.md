# HDRezka Downloader

Расширение для Chromium-браузеров (Arc, Chrome, Edge). Работает только на `rezka.fi`.

- Меню (иконка расширения): название, озвучка, сезон/серия, ссылки по всем качествам.
- Кнопка прямо на странице под плеером: выбор качества и скачивание в один клик.
- Настройки (в меню): шаблоны папки и имени файла, опция «спрашивать, куда сохранить».
  Папки задаются относительно «Загрузки» (ограничение браузера); для любой папки
  включите «Спрашивать, куда сохранить».

## Установка (Arc/Chrome)
1. Откройте `arc://extensions` (или `chrome://extensions`), включите «Режим разработчика».
2. «Загрузить распакованное расширение» → папка `extension/`.
3. Откройте страницу видео на rezka.fi.

Если домен сменится — поправьте `matches`/`host_permissions` в `manifest.json` и `HOST_RE` в `popup.js`.
