# HDRezka Downloader

Расширение для Chromium-браузеров (Arc, Chrome, Edge). Работает только на `rezka.fi`.

В меню показывает название, озвучку, сезон/серию (если есть) и ссылки на mp4 по всем
качествам. Файл сохраняется как `Название (год) - S02E02 - Озвучка - 480p.mp4`.

## Установка (Arc/Chrome)
1. Откройте `arc://extensions` (или `chrome://extensions`), включите «Режим разработчика».
2. «Загрузить распакованное расширение» → папка `extension/`.
3. Откройте страницу видео на rezka.fi, нажмите на иконку расширения.

Если домен сменится — поправьте `matches`/`host_permissions` в `manifest.json` и `HOST_RE` в `popup.js`.
